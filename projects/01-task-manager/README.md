# TaskFlow — Task Manager

A responsive task manager built with **HTML, CSS and vanilla JavaScript**. It is designed as a beginner-friendly project with practical DOM, events, state, and browser-storage examples.

## Features

- Add tasks with low, medium, or high priority.
- Mark tasks as completed and delete individual tasks.
- Filter by all, active, or completed.
- Search task titles.
- Summary counters and responsive layout.
- Saves tasks in browser `localStorage`; no account or server is required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a task. Refresh the page to confirm that it is saved.

You can also use the VS Code Live Server extension.

## Current limitations

Data is stored in the current browser only. This project does not yet include authentication, cloud sync, or a backend API.
